$ libtv --help
--------------------------------------------------------------------------------
用法： libtv [options] [command]

画布命令：登录、登出（logout）、账户（account）、项目、脚本（script）、节点、分组、上传、下载（download）、image（含
`image shortcut` Slash）、模型。当前项目默认读取当前目录 `.libtv/project.json`（`libtv project
use`）；默认分组见 `libtv group use`。

选项：
  -V, --version            显示版本号。
  -h, --help               显示本命令说明。

命令：
  login                    登录：浏览器（web）或手机验证码。
  logout                   退出登录：删除凭据文件、清除 LIBTV_TOKEN 与内存中的 token/webid 快照。
  account                  多账户：查看当前账户信息、列出可切换账户、切换生效账户（个人 / 团队）。
  project                  画布项目：新建、列表、更新、本地绑定(use/unuse)、画布摘要（含团队空间）。
  upload [options] <node>  媒体上传：上传文件并建资源节点。
  download [options]       下载节点资源到本地：`-n` 为节点 id
                           或显示名。图片/视频/音频单节点直存文件；普通分组与多文件场景输出 ZIP（对齐画布「批量下载」命名）。
  image                    图片类画布节点：Slash 快捷等子命令。
  script                   脚本节点相关命令（分镜图组等）。
  node [options] [node]    画布节点：`list` 列出（可选按分组）；`create` 仅新建（必填 -t）；`delete`
                           删除。以下为「已有节点」默认用法（须传节点名；不传名仅 `node` 时打印本帮助）。新建请用 `node
                           create`；默认子命令不接受 `-t`。
  group                    普通分组：`list` 列出画布上所有普通 group；`create <group>`
                           仅新建；`group [group]` 仅操作已有组（查询/绑定/`--node-rm`
                           解绑/`--run`；已 `group use` 时可省略
                           `<group>`）。`use`/`unuse` 维护 `.libtv/project.json`
                           默认分组。
  model [name...]          模型：`search` 在 supportModels 中检索（可选
                           `-t/--type`）；`libtv model <name...>` 对
                           modelKey/modelName 完全匹配后拉取完整 tool_spec schema。
  help [command]           显示子命令说明。

$ libtv login --help
--------------------------------------------------------------------------------
用法： libtv login [options] [command]

登录：浏览器（web）或手机验证码。

选项：
  -h, --help       显示本命令说明。

命令：
  web [options]    浏览器登录：启动本机回调服务，打印带 callback_url 的 LibTV 首页链接；登录成功后把 token 写入
                   ~/.libtv/credentials.json（与旧版 token 凭据格式一致）。
  phone [options]  手机登录：发短信、验证码两步。
                   先 -p 发短信，再加 -c 完成登录。
  help [command]   显示子命令说明。

--------------------------------------------------------------------------------

手机登录：发短信、验证码两步。
先 -p 发短信，再加 -c 完成登录。

选项：

  -c, --code <code>            短信中 6 位数字验证码。
  --captcha <captcha-payload>  人机验证返回串。接口要求时在网页完成验证；将网页返回的验证参数字符串填于此。
  -h, --help                   显示本命令说明。

                                  `--team-id <n>` 覆盖，`--team-id 0` 强制建到个人。

                                  默认走「当前活跃账户作用域」的 teamId（由 `libtv account use`

                                  强制查个人项目。
  update [options] <projectUuid>  项目更新：修改画布项目名称 / 简介 / 封面 / 所在文件夹（团队项目同样适用）。

                                  .libtv/project.json（会清除原默认分组绑定）。
  unuse                           解除当前目录与项目的绑定（删除 .libtv/project.json，同时解除默认分组）。

$ libtv node --help
--------------------------------------------------------------------------------
用法： libtv node [options] [command] [node]

画布节点：`list` 列出（可选按分组）；`create` 仅新建（必填 -t）；`delete` 删除。以下为「已有节点」默认用法（须传节点名；不传名仅
`node` 时打印本帮助）。新建请用 `node create`；默认子命令不接受 `-t`。

参数：
  node                     默认用法：目标节点 ID 或展示名；精确匹配，ID 优先。
                           无写参且未接管道仅列出匹配项。
                           无写参且标准输入为逐行 JSON 则补入边，缺边则创建。

选项：
  -p, --project <project>  目标项目 UUID（可选）。缺省见根命令 --help。
  -g, --group <group>      可选。父级普通分组：解析与改边仅限该组 childNodeIds。未传时若当前目录已 `libtv
                           group use` 绑定默认分组，则自动套用同一限定。
  --prompt <text>          写入节点参数中的提示词。与 --set 同用时后写覆盖同名键。
  --name <text>            将节点展示名更新为指定文本。
  -s, --set <pair>         改「生成器参数」（写
                           `data.params`）——影响模型这次怎么生成。键=值，可重复；仅拆分首个等号，值支持
                           true/false/数字/JSON。
                           可选字段见 `libtv model <model>`，常见如 model / ratio / count
                           / settings.*。
                           model 只接受模型名字（modelName），如 `-s model=可灵O1`（用 `libtv
                           model search` 查看可用名字）。
                           例：-s model=可灵O1  -s ratio=16:9  -s count=2 (默认： [])
  -u, --update <pair>      改「节点自身属性」（写 `data` 顶层，不含
                           `params`）——节点本体承载的内容，不影响模型参数。键=值，可重复；语法同 `--set`。
                           典型字段：文本的 `content`、脚本/分镜的 `rows` 等。
                           例：-u content='["Hello"]'  -u contentWidth=720
                           注意：展示名用 `--name`；`params` 用 `--set`/`--prompt`；`type`
                           不可改。 (默认： [])
  --left <node>            入边（确保）：上游节点ID或名称。ID优先；无则建边，有则不变。
                           注意：不可与 --left-add、--left-rm 同用。 (默认： [])
  --left-add <node>        入边（追加）：上游节点ID或名称。ID优先；可重复。 (默认： [])
  --left-rm <node>         入边（移除）：上游节点ID或名称。ID优先；可重复。 (默认： [])
  --right <node>           出边（确保）：下游节点ID或名称。ID优先；无则建边，有则不变。
                           注意：不可与 --right-add、--right-rm 同用。 (默认： [])
  --right-add <node>       出边（追加）：下游节点ID或名称。ID优先；可重复。 (默认： [])
  --right-rm <node>        出边（移除）：下游节点ID或名称。ID优先；可重复。 (默认： [])
  --x <n>                  与 `node create` 联用：画布 X（像素）（由父级 `node` 解析，勿在 create
                           上重复声明）。 (默认： "0")
  --y <n>                  与 `node create` 联用：画布 Y（像素）（由父级 `node` 解析，勿在 create
                           上重复声明）。 (默认： "0")
  -r, --run                主流程成功后触发生成一次。管道为逐行 JSON 时可串联下游画布节点命令。
  -h, --help               显示本命令说明。

命令：
  list [options]           列出画布节点。
  create [options] <node>  新建画布节点（-t 必填）；支持 --left/--right 与
                           --left-add/--left-rm 等；--group
                           限定在父分组的子节点内解析并将新节点挂入该组。画布坐标请用父级「libtv node」的
                           --x/--y（勿与 create 重复声明，否则坐标会落为 0）。
  delete [options] <node>  删除指定节点及其全部连线。

  --left-rm <node>         入边（移除）：上游节点ID或名称。ID优先；可重复。 (默认： [])
